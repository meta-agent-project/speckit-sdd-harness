# Phase 2a mockup 브리프 (design-shotgun 입력)

강의 영상·강사 발표용 슬라이드 화면. 무대 1920×1080, 미니멀, 한국어 매우 굵은 고딕(Pretendard 800~900), 코드는 D2Coding.

## 고정: 템플릿 1번 `01-capsule-black` 틀
- 바탕: 연한 점 격자 배경
- 가운데 흰 카드: 굵은 검정 테두리 + 둥근 모서리 + 우하단으로 떨어지는 단단한 검정 그림자
- 카드 왼쪽 위 테두리에 걸친 검은 캡슐 라벨(흰 글자): "AI 활용 · 1차시 기본 개념 · 게임으로 이해하기"
- 카드 오른쪽 위 회색 쪽번호 `01 / 03`
- 카드 왼쪽 아래 얇은 진행 막대
- 화면 하단 자막 영역은 비워 둔다(강의자료에는 자막 없음)

## 장면 3개 (모두 위 틀 안에)
1. 큰 문장: 제목 "AI라는 팀원을 얻었습니다" + 강조 블록 "그런데 퀘스트를 모릅니다"
2. 판서: 사각형 → 글자 → 화살표 (3단계, 손으로 그린 듯한 선)
3. 코드 타이핑: Java 코드 2단계 + 마지막에 실행 결과

## 비교할 것 (시안 여러 개)
- 판서 선 느낌: 매끈한 선 / 약간 흔들리는 손그림 / 마커 느낌 굵은 선
- 코드 패널 모양: 어두운 패널 / 밝은 패널 / 카드와 같은 굵은 테두리 패널, 실행 결과 표시 위치
- 발표 조작(그림만, 구현은 2b): `T` 이론 카드 목차, `N` 발표자 노트, `P`/`E`/`C` 직접 판서 도구, 멈춤 타이머 — 화면을 덜 가리는 배치
